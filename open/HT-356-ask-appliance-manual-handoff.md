# HT-356 · Find the right appliance manual from Ask or the homepage

**Repo:** both
**Priority:** P1
**Created:** 2026-11-19
**Status:** Open

## Homeowner outcome

“Can you find the manual for my washing machine?” is one job. The homeowner should be able to ask it without knowing which documents HomeTruth holds. HomeTruth checks authorised evidence first and returns a suitable exact-model manual with its edition status. If that check finds no suitable copy, HomeTruth continues the same request into manufacturer lookup. The homeowner never has to tell HomeTruth what it holds or choose a source. Let the homeowner ask a question and see the passage that supports the answer.

## Entry and action contract

- Typed Ask offers a selectable **Find a manufacturer’s manual** action for a manual-finding request. The action payload is `{ "actionId": "find_appliance_manual" }`. Both the anonymous and signed-in Ask clients should understand this offer. Keep ordinary questions conversational, including questions about the contents of a manual already selected.
- Reuse the same action ID already carried by the Improving starter in HT-349 / frontend PR #16. Route by ID so changing the label or language preserves behaviour. Public entry opens the labelled preview and can carry the intent through sign-in. The public starter, a free-text submission, ordinary navigation, sign-in continuation and refresh each make zero paid specialist calls.
- In the live signed-in pilot, reuse the already-confirmed home, appliance and full model. Skip the picker when that context is sufficient. Ask only for a genuinely missing or ambiguous detail. Use the HT-341 identification flow if the full model is missing. The server rechecks property, item and document access at use time. A remembered action carries intent only.
- Keep selection of a known action in the product handoff layer. The backend maps it to the existing appliance endpoint, registry and domain service. The client cannot choose a runtime revision, tool or spending limit. Parent/child messaging is outside this ticket.

## Manual resolution and acceptance

1. **Do we have it?** Inspect the appliance’s private evidence and relevant authorised home documents. Return a permitted, readable, suitable exact-model manual directly with its source and a way to open it or ask a question. This path requires zero paid reservations or lookup confirmations. If an unlinked document is a possible match, show the evidence for that match and ask before associating it. Handle multiple variants, unreadable files and unavailable sources explicitly. A user with read access may open permitted evidence; lookup and import require their existing write permissions.
2. **Is it current?** Show the exact model/variant and market, edition or revision, source, and last verification date where known. An exact match can still have unknown currency. Say “latest edition unverified” when the manufacturer provides insufficient evidence. A recent upload or successful indexing does not establish currency. If a newer official edition is evidenced, show both and offer review. Keep the existing copy and its provenance until the homeowner acts.
3. **Continue the same task when a search is needed.** HomeTruth selects manufacturer lookup when the authorised evidence check finds no suitable manual, or when the requested edition check requires an external lookup. Before paid execution, show the specific appliance and full model, with clear copy that HomeTruth will use a saved manual if suitable and otherwise search the manufacturer. A deliberate action such as **Find the manual for my Bosch W100** on that scoped offer supplies the one required confirmation. If Ask already obtained that confirmation, the shared flow consumes it once without asking again. If the request arrived through generic text, preview or an unscoped action, obtain confirmation once after resolving the appliance; the final appliance-selection control may also confirm the search if its wording is explicit. Previously confirming a model establishes identity only. Bind execution intent to the current authenticated principal, home, item, model and request key; invalidate it if the scope or identity changes. Recheck permission and use the item-scoped manual-search POST with the same key on retry. Respect HT-351 admission and offer the official finder or upload fallback when lookup cannot complete.
4. **Keep it and answer from it.** Show cited candidates. The homeowner separately confirms which candidate to save. Reuse HT-341’s verified PDF import, deduplication, private appliance association, provenance and indexing. Show pending, ready or failed indexing accurately. Retrying indexing must reuse the saved document. A support-page link alone cannot support a claim about the manual’s contents. Once ready, answer from authorised evidence with a verifiable passage citation; surface an unknown when evidence is missing.
5. **Is there a warranty?** Offer an optional warranty check from the result without interrupting the manual journey. Reuse HT-341 purchase and warranty evidence. Show sourced terms, relevant dates and uncertainties; distinguish a manufacturer's general warranty from evidence of this unit's purchase, registration or coverage. If unresolved, offer to attach a receipt or warranty document. Warranty lookup never silently starts another paid manual search.

## Verification before closure

- Exercise the public starter, anonymous typed Ask, sign-in continuation and authenticated typed Ask. Each resolves the same action ID. Verify the preview with pilot off and the live picker with pilot on. Include unrelated prompts and an already-selected manual question.
- Trace both paths from one typed request. For a confirmed appliance with a suitable saved copy, show the manual directly: zero picker prompts, source choices, paid calls or reservations. For the same confirmed appliance with no suitable copy, one clearly scoped action authorises the fallback: zero repeat confirmations, exactly one paid run and one reservation even on duplicate submission. With two plausible washers, ask which one, then combine selection and confirmation wherever the full model and search intent can be shown together.
- Guest preview, sign-in resume, generic action selection, navigation, cancellation and refresh cannot authorise paid execution. A changed appliance or model invalidates the old confirmation; loss of permission prevents execution and disclosure. Candidate review and confirmation before saving remain a separate decision.
- Use fixtures for an exact current edition, unknown edition, a superseded edition, a different model suffix, and no match. Verify separate search and save confirmations, preserved history, deduplication, indexing failure/retry, a passage-backed answer after reload, and warranty evidence present/absent.
